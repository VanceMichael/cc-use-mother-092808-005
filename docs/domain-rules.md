# 领域边界与规则

核算央企战略性新兴产业、研发和公共服务的价值贡献。

## 统一维护的对象

- **组织边界**：集团、产业板块、研究院、公共服务单位的树形边界；
  重组（合并/分立/更名/划转）以生效期事件登记，源单位转出权重合计
  必须为 1，历史贡献按权重平移到目标单位。
- **产业分类**：产业目录及战新标记；项目改挂战新分类必须经证据审批。
- **项目任务与投资批次**：项目可拆分为任务、批次；项目拆分权重合计
  为 1，拆分后父项目停止接报。
- **分摊规则**：按项目 / 项目+任务 / 项目+任务+批次三级作用域生效，
  粒度从细到粗回退；份额合计恰为 1，版本化、旧版本只失效不删除。
- **贡献记录**：项目产出（收入、增加值）、研发费用（含基础研究
  申请位）、成果转化、公共服务、集团内部交易。

## 贡献公式（FORMULA_VERSION = 2030-plan-v1）

- 作用域毛额 = 该作用域内各方申报之和。
- 份额后归属 = 作用域毛额 × 经批准份额（末位单位承接一分钱舍入差，
  合计分文不差）。
- 净增加值 = 毛增加值 − 已确认内部交易增加值抵销。
- 战新增加值 = 战新项目全部增加值 + 非战新项目中逐笔获批的战新产出；
  分子分母同口径抵销战新项目内部交易。
- 战新增加值占比 = 净战新增加值 / 净增加值。
- 基础研究投入占比 = 已批准的基础研究费用 / 研发费用总额。
- 研发经费增速 = 本期研发费用 / 上一已关账期研发费用 − 1。
- 目标差额：比率类为 目标 − 实际（正=尚差）；增速类为 实际 − 目标
  （正=超额）。同比以上一已关账期快照为准。

## 内部交易抵销

- PENDING 不得抵销，阻断关账；DISPUTED 进复核队列，只有 REVIEWER
  能裁决；MATCHED 才进入抵销过程并在报告中留卖方、买方、确认人。
- 集团对外口径只保留抵销后的净影响；内部交易更正只允许改金额。

## 研发属性与特殊归类

- 申请位（claimed_strategic / basic_claim）只是意图，不计数。
- 认定必须附证据编号，走 SUBMITTED → APPROVED/REJECTED，提交人
  永远不能批准自己的申请（复核人提交的也一样）。
- 未批准的申请是关账阻断项，并生成指向报送单位的持久化催补。

## 规划目标偏差

- 三类目标：战新增加值占比、研发经费年均增长率（>7%）、基础研究
  投入占比（≥15%）；战新占比目标可附基期值（基期 + 5 个百分点）。
- 目标只能由 PLANNER 在 OPEN 期间修改；CLOSING/CLOSED 期间拒绝。
- 开放期改目标不影响任何已关账历史期间（历史读自己的快照）。

## 关账冻结

关账快照（`snapshots` 表，按报告期 + revision）冻结：公式版本、
组织范围与重组映射、产业目录、项目与拆分、分摊规则与份额、目标、
全部贡献记录、审批记录及计算结果。冻结后：

- 拒绝一切写入（目标、报送、规则、主数据、批次）；
- 管理层报告一律返回最新快照，不重新计算；
- 用快照中的数据集重放 `compute_report`，结果与快照逐位一致。

## 更正版本

- 仅 CLOSED 期间可发起；DATA_OFFICE 提交、REVIEWER 批准，双人。
- 只允许改金额与证据等业务列（见
  `CORRECTION_ALLOWED_COLUMNS`）；不得改报送单位、报告期、公式、
  组织范围与审批留痕。
- 批准时校验：重算后不得新增关账阻断项（例如不能借更正补一个没有
  证据的战新申请）；通过后用同一公式版本生成 CORRECTION 快照。
- 原 CLOSE 快照永久保留；驳回不落任何修订。

## 批量导入

- 批次唯一键 =（报告期，客户批次号）；内容用规范化 JSON 指纹。
- 指纹相同 = 完全重送，幂等忽略；同批次号不同内容拒收（防覆盖）。
- 行级去重键 = 报告期 + 类型 + 来源凭证号 + 报送方 + 项目；内容
  一致记 DUPLICATE，不一致记 CONFLICT 并挂复核队列（先不入库）。
- 冲突行只有 REVIEWER 可裁决接受/驳回；已关账期间冲突不得直接
  落库，必须走更正版本。

## 重启恢复

- 关账作业（jobs）与催补（reminders）都持久化；`execute_close_job`
  幂等，可重复调用，成功/阻断都会自行提交。
- `resume_jobs` 在进程启动时续跑所有未完成关账；
  `sweep_reminders` 对账：缺口仍在不重复堆积，缺口消失自动核销。

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实
个人信息、账号或凭据。
