# 领域边界

核算央企战略性新兴产业、研发和公共服务的价值贡献。

现有领域资料围绕以下边界组织：

- 组织与项目边界
- 贡献公式
- 内部交易抵销
- 研发属性
- 规划目标偏差

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 治理后端不变量

`src/valuegov/` 实现并强制以下规则：

- 报告期关账后，公式版本、组织范围与规划目标随快照冻结；已关账期间只读，历史错误通过更正版本（新版本的记录链）处理。
- 战略性新兴产业归类与基础研究属性属于特殊归类：业务单位提交证据，复核人员审批，提交人不得自行批准。
- 联合项目的跨单位分配规则在同一期间权重合计必须为 1，集团汇总因此不会重复计算；项目拆分后父项目停止入账，子项目继承协作结构；重组自生效期间起把贡献归属承继单位。
- 内部交易必须经抵销运行处理，集团口径只保留抵销后的净影响；已抵销的交易不得更正，只能在开放期间记录反向交易。
- 关账前必须清空待审批证据、待审批更正与未抵销交易；关账由持久化作业执行，进程重启后未完成的关账与证据催补继续。
- 批量导入按幂等键识别重送；内容不一致或无法入账的材料进入复核队列，由复核人员决定维持原样或以更正版本替换。
- 规划目标只能写入开放或未来期间；管理层报告同时给出冻结快照与纳入关账后更正的重述视图，差额以目标为准。
